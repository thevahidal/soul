# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version  | Supported          |
| -------- | ------------------ |
| 0.9.x    | :white_check_mark: |
| < 0.9    | :x:                |

## Reporting a Vulnerability

Please do not open a public issue. Report it privately through GitHub:
https://github.com/thevahidal/soul/security/advisories/new

You can expect an initial response within a few days. If the report is accepted,
we will work on a fix and publish it in a new release with credit to the reporter
(if wanted). If it is declined, we will explain why.
